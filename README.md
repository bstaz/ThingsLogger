# ThingsLogger

Log completed [Things3](https://culturedcode.com/things/) tasks to a directory using a Jinja2 template.

See the example Jinja2 template (set up for use with Obsidian) in the [contrib](contrib/) directory.

## Requirements

- [things-py](https://thingsapi.github.io/things.py/things.html)
- Rich
- SQlModel
- psycopg2
- Pydantic Settings
- Jinja2
